Начальная версия приложения состоит ровно из трёх файлов:
1. app.py — запускает контрольный расчёт и показывает результат.
2. pricing.py — содержит функцию divide для деления суммы на части.
3. README.txt — описывает назначение учебного проекта и его файлы.

Репозиторий используется для практики клонирования, обмена коммитами,
ветвления, слияния, разрешения конфликтов и работы с историей Git.
Рабочие копии person1, person2 и person3 имитируют трёх разработчиков.
В индивидуальной части создаётся воспроизводимая ошибка деления на ноль,
после чего git bisect находит первый ошибочный коммит за шесть проверок.
Последующие этапы добавляют новые файлы для отдельных упражнений.
Run: python app.py
